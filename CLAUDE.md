# LOTR Marathon RSVP

Static GitHub Pages site (https://lennartelbe.github.io/lotr-marathon/).

## Rules

- **No emojis, no invented images.** Where an emoji or image is wanted, insert a clearly marked placeholder (e.g. an `<img>` pointing at `assets/<descriptive-name>.png` with alt text) and add the file to the "Assets to find" list in your reply so the user can source it into `assets/`.
- Use assets that already exist in `assets/` instead of emojis (e.g. the ring).
- Commit without asking for approval of the message; just write a clear one.
- Never add Co-Authored-By or other AI attribution to commits or PRs (global rule).
